# 提交信息生成器

- 默认重新读取 `git diff --cached --name-only`、`git diff --cached --stat` 和 `git diff --cached`，不使用旧上下文代替当前变更。用户明确指定其他范围时使用该范围。
- 默认暂存区为空时说明没有暂存变更，不自动暂存文件或改用工作区内容。
- 读取项目提交规范和最近 5–10 条提交，按用户要求、项目规范、历史惯例的顺序确定语言、前缀、标点与格式；没有约定时使用简短清晰的描述，不强制中文或 emoji。
- 锁文件先查看变更概况，仅在确认依赖变化所需时读取相关片段，避免输出完整大型锁文件。
- 根据实际 diff 概括目的和主要行为变化；不添加未经验证的测试结论。仅在有助于说明变更时添加正文。
- 成功时只输出包在 markdown 代码块中的提交信息；缺少变更或无法读取 Git 时简短说明原因。
- 本技能只生成信息；提交、暂存或推送需要用户另外授权。
